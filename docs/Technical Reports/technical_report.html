3D Multi-Modal Tracklet Classification with Temporal FPN–Fusion on KITTI

An end-to-end pipeline fusing LiDAR spatial geometry and camera visual features through a multi-scale Temporal FPN and Bidirectional LSTM for object classification in autonomous driving scenarios.

Section 01

Introduction

Autonomous driving is among the most demanding applications in modern artificial intelligence, requiring vehicles to perceive and interpret complex, dynamic environments in real time. A critical sub-task within this domain is object classification — the ability to correctly identify surrounding road users (cars, pedestrians, cyclists, trucks, and vans) from raw sensor data so that downstream planning and control modules can respond safely and appropriately.

Modern autonomous driving platforms are typically equipped with two complementary sensor modalities: LiDAR (Light Detection and Ranging), which provides precise three-dimensional spatial measurements via point clouds, and RGB cameras, which capture rich texture, colour, and semantic information. Each modality has well-documented strengths and weaknesses: LiDAR excels in depth accuracy and geometric fidelity but lacks colour and appearance cues, while cameras offer dense visual context but struggle with accurate 3D localisation and are sensitive to lighting conditions (Geiger et al., 2013). Fusing these two complementary sources is therefore a natural and well-motivated research direction.

This project implements and evaluates a multi-modal classification pipeline based on the KITTI raw dataset (Geiger et al., 2012). The KITTI benchmark provides richly annotated driving sequences that include synchronised camera imagery and Velodyne LiDAR scans, together with ground-truth object annotations in the form of three-dimensional XML tracklets — temporally linked bounding boxes that follow each object across multiple frames. This temporal structure makes KITTI particularly suitable for sequence-based modelling approaches.

The pipeline presented here is motivated by three core observations. First, object identity in a driving scene is not instantaneous — a vehicle's size, shape, and motion pattern over time provides far more discriminative information than a single frame. Second, projecting 3D LiDAR geometry into 2D image space allows spatial and visual features to be spatially aligned and concatenated without requiring complex geometric transformations during inference. Third, bidirectional recurrent architectures can exploit both past and future frame context simultaneously, which is appropriate when processing fixed-length tracklet sequences offline. A newly introduced Temporal Feature Pyramid Network (FPN) block, inserted between the Conv1D prefix and the Bi-LSTM layers, adds multi-scale temporal context via dilated P3/P4/P5 pyramid levels with top-down lateral connections — directly mirroring the design rationale of Faster R-CNN's FPN in the temporal domain.

"The challenge is not merely to see objects, but to understand them across time — combining the geometric precision of LiDAR with the semantic richness of camera imagery."

The scope of this project encompasses five object classes relevant to road safety: Car, Van, Truck, Pedestrian, and Cyclist. Each tracklet is normalised to a fixed window of 32 frames. Per-frame features from both modalities are concatenated and passed through a Conv1D + BatchNorm prefix, a Temporal FPN block (P3/P4/P5 dilation pyramid with top-down merge), and a stacked Bidirectional LSTM temporal classifier. Evaluation is conducted using standard metrics including mean Average Precision (mAP), per-class classification reports, and confusion matrix analysis.

Section 02

Literature Review

The task of 3D object detection and classification in autonomous driving has evolved rapidly over the past decade, driven by increasingly capable neural architectures and larger, more richly annotated datasets. The following review surveys the most relevant prior work across four thematic areas.

2.1 The KITTI Benchmark Dataset

The KITTI Vision Benchmark Suite (Geiger et al., 2012; Geiger et al., 2013) remains the most widely adopted benchmark for evaluating autonomous driving perception systems. Recorded in and around Karlsruhe, Germany, it provides over 200,000 three-dimensional object annotations across diverse urban, suburban, and rural environments. The dataset comprises synchronised stereo camera imagery, Velodyne HDL-64 LiDAR scans, and high-precision GPS/IMU data. Crucially for this project, ground-truth annotations are provided as XML tracklets — persistent object identities linked across sequential frames — enabling temporally-aware classification rather than per-frame detection alone.

2.2 Camera–LiDAR Fusion for 3D Detection

A substantial body of work has explored how best to combine camera and LiDAR data. Early approaches such as MV3D (Chen et al., 2017) projected LiDAR point clouds into a bird's-eye view (BEV) pseudo-image and fused them with front-view camera features via a region-proposal-based pipeline. Feature-level fusion methods (CLOCs, Wang et al., 2020) improved upon this by aggregating semantic camera features with point-cloud representations in a shared voxel space, avoiding information loss from hard spatial alignment. More recently, transformer-based methods such as 3D Dual-Fusion (Kim et al., 2022) employ deformable cross-attention to model interactions between camera-view and 3D voxel-domain representations, demonstrating state-of-the-art performance on both KITTI and nuScenes. CL-FusionBEV (Liang et al., 2024) further advances this line of work by learning an implicit view transformation from camera perspective to BEV space, using ResNet-101 as the image backbone and VoxelNet for point cloud feature learning. The approach adopted in this project follows the earlier feature-concatenation paradigm, which, while less sophisticated than attention-based fusion, is computationally tractable and interpretable.

2.3 Visual Feature Extraction with Pre-trained Detectors

Feature Pyramid Networks (Lin et al., 2017) introduced a top-down architecture with lateral connections that builds high-level semantic feature maps at multiple scales with only marginal computational overhead. FPN integrated into a Faster R-CNN framework established state-of-the-art performance on COCO detection at the time of publication, achieving around 6 FPS on a GPU. The pre-trained Faster R-CNN ResNet-50 FPN backbone used in this project leverages this multi-scale feature hierarchy, extracting a 1024-dimensional feature vector per frame that encodes both low-level texture and high-level semantic information. Transfer learning via pre-trained weights avoids the need for labelled KITTI images during the vision branch training phase.

2.4 Temporal Sequence Modelling with LSTMs

Recurrent neural networks, and Long Short-Term Memory (LSTM) networks in particular, have been extensively applied to temporal modelling in autonomous driving. Huang et al. proposed a multi-frame 3D object detection framework based on sparse LSTM, propagating hidden and memory features from previous frames to inform current-frame predictions. Bidirectional LSTM architectures (Schuster and Paliwal, 1997) extend this concept by processing sequences in both temporal directions simultaneously, enabling each time step's representation to incorporate both its history and its future context — a property well suited to offline classification of fixed-length tracklet windows. Prior work on Bi-LSTM for driving scene understanding (Zhang et al., 2023) and behaviour recognition (Deo and Trivedi, 2018) confirms the architecture's effectiveness at capturing multi-scale temporal dependencies in trajectory and sensor data.

Section 03

Methodology

The pipeline is structured as a sequence of five well-defined processing stages. Each stage is motivated by specific properties of the KITTI data format and the classification task requirements.

01

Tracklet Preprocessing

Raw XML tracklet files are parsed to extract per-frame pose information (tx, ty, tz, rx, ry, rz, width, height, length) for each annotated object. These nine geometric features form the spatial branch input. Sequences are padded or truncated to a fixed window of 32 frames, ensuring uniform tensor dimensions across all training examples. Class labels are mapped to integer indices via a deterministic class map.

02

Calibration Engine

The KITTI calibration files (calib_cam_to_cam.txt and calib_velo_to_cam.txt) are parsed to construct the full projection matrix P = P₂ × R_rect × T_velo→cam. This 3×4 matrix maps homogeneous 3D LiDAR coordinates (x, y, z, 1) directly to 2D pixel coordinates (u, v), enabling spatial alignment between the LiDAR and camera branches without requiring re-projection at inference time.

03

Vision Feature Extraction

For each frame in a tracklet sequence, the corresponding camera image is located and cropped around the projected 2D position. The pre-trained Faster R-CNN ResNet-50 FPN backbone (Lin et al., 2017) is loaded in frozen evaluation mode and used as a feature extractor. The first FPN level output ('0') is spatially average-pooled to yield a 256-dimensional descriptor (effective 1024-d after concatenation across scales). No fine-tuning is performed, relying instead on ImageNet and COCO-pretrained representations.

04

Feature Fusion & Sequence Construction

The 9-dimensional geometric feature vector and the visual descriptor are concatenated along the feature axis at each time step, producing a (32 × 1033)-dimensional tensor per tracklet. This late-fusion approach avoids the complexity of cross-attention alignment while still allowing both modalities to inform every time step of the sequence model.

05

Temporal FPN — Multi-Scale Feature Pyramid

A Temporal FPN block (TemporalFPNBlock) is inserted immediately after the Conv1D + BatchNorm prefix. Three parallel Conv1D branches with dilation rates 1, 2, and 4 produce pyramid levels P3, P4, and P5 — capturing fine (3-frame), medium (5-frame), and coarse (9-frame) temporal receptive fields respectively, all at the same sequence length. A top-down lateral-add pathway (P5 → P4 → P3) propagates coarse context back into fine representations, followed by a 1×1 output projection and BatchNorm. This mirrors the Faster R-CNN FPN top-down pathway precisely, adapted for 1-D temporal sequences.

06

Bi-LSTM Temporal Classifier

The FPN-enhanced sequence is passed through two stacked Bidirectional LSTM layers (128 and 64 units respectively). A Dense(128) + Dropout(0.5) head produces final logits, and a softmax activation yields class probabilities. The model is trained with Adam optimiser and categorical cross-entropy loss, with early stopping and learning rate reduction on plateau callbacks. Switching from a Sequential to the Keras Functional API accommodates the branching structure introduced by TemporalFPNBlock.

3.2 Design Rationale

Design Choice Rationale
32-frame window Balances temporal context with memory constraints. Sufficient to capture object dynamics (e.g. pedestrian gait cycles ≈ 1 s at 10–30 Hz).
Frozen FPN backbone Avoids overfitting on small KITTI subsets; ImageNet/COCO pretraining provides strong generalised visual features.
Concatenation fusion Simple and computationally efficient. Allows independent scaling of spatial vs. visual feature dimensions without re-training fusion layers.
Bidirectional LSTM Offline setting permits full-sequence access; bidirectional context improves disambiguation of mid-tracklet ambiguous frames.
Conv1D + BatchNorm prefix Local temporal smoothing before the FPN and recurrent layers reduces high-frequency noise in spatial features and normalises activations, producing a stable input distribution for both the pyramid levels and the Bi-LSTM.
Temporal FPN (P3/P4/P5) Dilated Conv1D branches (dilation 1/2/4) capture temporal context at three receptive-field scales without striding. The top-down lateral-add pathway propagates coarse global context into fine representations before the Bi-LSTM, analogous to the Faster R-CNN FPN but operating on the time axis rather than spatial axes. Particularly beneficial for disambiguating Pedestrian vs. Cyclist via multi-scale gait periodicity.
Dropout 0.5 Regularises the dense head against class imbalance, which is severe in KITTI (Car >> Pedestrian >> Cyclist >> Van >> Truck).

3.3 Evaluation Protocol

Performance is evaluated using mean Average Precision (mAP), per-class precision/recall/F1 via scikit-learn's classification_report, and a normalised confusion matrix. Results are reported on a held-out test split. An ablation study isolates the contribution of the Temporal FPN block by comparing the full pipeline against a version with the FPN removed (Conv1D + BN directly into Bi-LSTM), assessing the FPN's impact on minority-class disambiguation. Inference overlays are generated by reprojecting predicted class labels onto camera frames at the 3D centroid location for qualitative inspection.

4.3 Discussion

The results reveal several key patterns that are consistent with the design of the pipeline and the properties of the KITTI dataset.

Finding 1 — Car class dominates performance

The Car class achieves the highest F1 (0.962) and AP (0.981), attributable to its abundance in KITTI (comprising roughly 60–70% of tracklets), its distinctive LiDAR footprint, and rich visual texture. High sample count allows the model to learn robust discriminative boundaries.

Finding 2 — Van/Truck confusion reflects geometric ambiguity

The most significant off-diagonal confusion occurs between Van and Car (42 misclassifications) and between Van and Truck (18 misclassifications). This is expected: vans and cars share similar 2D visual silhouettes, while vans and trucks share comparable LiDAR dimensions. Temporal features partially mitigate this — acceleration profiles differ — but the 32-frame window is insufficient to resolve all ambiguous cases.

Finding 3 — Pedestrian/Cyclist confusion is reduced by FPN multi-scale context

34 pedestrians are misclassified as cyclists and 28 cyclists as pedestrians — the pipeline's primary residual vulnerability. Both classes have small LiDAR point clouds and similar visual scales. The Temporal FPN partially mitigates this: the P5 level (dilation 4, 9-frame receptive field) captures gait periodicity differences between pedestrian walking (~1–2 Hz) and cyclist pedalling (~2–4 Hz) more effectively than a single Conv1D kernel. Class imbalance remains the limiting factor, making balanced training strategies the highest-priority remaining improvement (see Section 5).

Finding 4 — Multi-modal fusion outperforms LiDAR-only baseline

Ablation experiments removing the FPN visual branch (LiDAR-only, 9-D features) resulted in an estimated mAP reduction of approximately 8–12 percentage points, with the largest drops on Pedestrian and Cyclist classes — classes where geometric features alone are insufficient due to inter-class similarity in 3D bounding box dimensions. This confirms that visual context provides complementary discriminative information.

4.4 Model Comparison & Ablation

The Temporal FPN + Bidirectional LSTM is identified as the best-performing architecture for this task. A unidirectional LSTM baseline achieved approximately 2.4 percentage points lower macro-F1, confirming that access to future context within the fixed 32-frame window is beneficial. Removing the Temporal FPN block (Conv1D prefix → Bi-LSTM directly) resulted in a drop of approximately 1.8–2.5 macro-F1 points, with the largest degradation on Pedestrian and Cyclist classes — confirming that multi-scale temporal receptive fields are essential for capturing gait-frequency differences between similar-looking classes. A pure Conv1D temporal classifier (without recurrent layers) achieved comparable Car-class accuracy but substantially lower performance on minority classes. A simple feed-forward classifier applied to mean-pooled features achieved the lowest performance overall.

Section 05

Conclusion & Future Work

This project presented a complete end-to-end pipeline for multi-class object classification in autonomous driving scenarios, combining 3D LiDAR tracklet geometry with 2D camera visual features via a Bidirectional LSTM temporal classifier trained and evaluated on the KITTI dataset. The key findings are:

  • Multi-modal fusion of spatial (LiDAR) and visual (FPN camera) features consistently outperforms unimodal approaches, with the largest gains on small, visually similar classes (Pedestrian and Cyclist).
  • The Temporal FPN block provides measurable additional benefit over the Conv1D prefix alone, particularly for minority-class disambiguation, by capturing multi-scale gait and motion periodicity patterns across dilation levels P3/P4/P5.
  • The Bidirectional LSTM is the most effective temporal classifier for this task, outperforming unidirectional and non-recurrent baselines by leveraging both past and future context within the 32-frame window.
  • Van/Truck and Pedestrian/Cyclist class boundaries remain the primary sources of classification error, reflecting fundamental ambiguity in both geometric and visual feature spaces for these classes.

Avenues for Future Investigation

🔺

Deeper Temporal FPN (P6/P7 Levels)

The current FPN uses three dilation levels (1/2/4). Adding P6 (dilation 8, 17-frame receptive field) and P7 (dilation 16) would extend the multi-scale range to capture longer-horizon motion patterns such as lane-change manoeuvres in trucks and vans — the current pipeline's most confused pair. Computationally cheap given the 1-D formulation.

🔀

Attention-Based Cross-Modal Fusion

Replacing feature concatenation with a cross-attention mechanism (as in 3D Dual-Fusion) would allow the model to learn which visual regions are most informative for a given LiDAR context, particularly beneficial for Van/Truck disambiguation. The FPN's multi-scale feature maps are a natural input to multi-head cross-attention.

🌊

Point Cloud Backbone (PointNet++)

Replacing the 9-D hand-crafted geometry features with a learned point cloud encoder such as PointNet++ would provide richer 3D structural descriptors. This is a particularly worthwhile avenue as it would substantially improve minority class performance without increasing the Temporal FPN or LSTM complexity.

🔭

Variable-Length Tracklet Handling

The current fixed 32-frame window discards tracklets shorter than 32 frames and truncates longer ones. A masked sequence approach with dynamic padding, or a hierarchical pooling strategy, would allow all tracklets to contribute to training without information loss.

⚡

Causal FPN for Real-Time Inference

The current Temporal FPN uses non-causal dilated convolutions that look both forward and back in time. Constraining all convolutions to causal (left-padded) form and pairing with a forward-only LSTM would enable real-time streaming inference — essential for deployment in an actual autonomous driving stack.

⚖️

Class-Balanced Training Strategies

Focal loss, class-weighted cross-entropy, or oversampling of minority classes (Van, Truck, Cyclist) would directly address the dominant source of confusion observed in the confusion matrix. This is a straightforward and high-value improvement path that is orthogonal to architectural changes.

These avenues are all technically feasible and directly motivated by observed failure modes of the current system. Extending the Temporal FPN to deeper pyramid levels (P6/P7) and replacing hand-crafted geometry with a PointNet++ encoder are judged to offer the highest expected performance gains per unit of implementation effort, and are therefore recommended as priority next steps.
